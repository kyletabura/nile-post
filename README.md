# The Nile Pen

Independent voices on climate justice, South Sudan politics and human rights.

## Files
- index.html — the whole website (pages, articles, Live updates, chatbot)
- 404.html — same site, shown for any wrong address
- og-image.png — preview image shown when the link is shared (WhatsApp, X, LinkedIn, Facebook)
- favicon.png, apple-touch-icon.png, icon-512.png, site.webmanifest — browser tab / home-screen icons
- robots.txt, sitemap.xml — tell Google how to index the site
- .nojekyll — tells GitHub Pages to serve files as-is

## Before uploading
Replace YOUR-USERNAME and the-nile-pen with your GitHub username and repository name in:
index.html, 404.html, robots.txt, sitemap.xml (use your editor's Find & Replace on `YOUR-USERNAME.github.io/the-nile-pen`).

## Publish
1. Create a repository (e.g. the-nile-pen) and upload every file in this folder.
2. Settings → Pages → Source: Deploy from a branch → main → / (root) → Save.
3. Live at https://YOUR-USERNAME.github.io/the-nile-pen/ after a minute or two.
4. Test the share preview at https://www.opengraph.xyz/.

## Chatbot
Inside the design editor the chatbot gives full AI answers. On the published site it searches every story and replies with the most relevant ones and links. Full AI answers on the live site need a small server with an API key.
