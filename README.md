# The Nile Pen

Independent voices on climate justice, South Sudan politics and human rights.

## Publish with GitHub Pages
1. Create a new repository and upload `index.html` (and this README).
2. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Your site will be live at `https://<username>.github.io/<repo>/`.

Story and stock images load from their original web addresses, so the site needs an internet connection.
